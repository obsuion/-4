## Decision proof and unsupported claims

The original acceptance predicate is equal regimes AND no near-guard sample
AND error norm <=1. A complete validated full sample with near_guard therefore
proves this proposal cannot be accepted; its halves are unperformed. Otherwise
the complete validated first sample can prove rejection by its near_guard or a
full/first regime mismatch. Only remaining proposals perform second and the
original error norm. Priority is full-near, first-near, first-regime. Measured
reason flags can overlap and cannot be summed as independent fractions.

Every performed leaf retains its original physical arithmetic and guards.
Initial metric shape/finite values/units and complete performed sample order
are checked before an early skip. Caller-owned physical preflight still runs;
the closed typed interface still requires its exact static/dynamic/model/
hardware/role owner and stationary unloaded HOLD domain. Generic supplied-step
execution retains the caller's responsibility for its physical input guards.
Arbitrary callback physics is not certified. The old compiled B63 native owner
does not implement this new work class; use the closed typed consumer or the
explicit Python owner, rather than silently invoking an unsupported legacy C
backend.

Halving, minimum/detailed fallback, shortened boundary clocks and selected
two-half arithmetic remain unchanged. Full is never accepted instead of the
two-half trajectory. Second mutates first's scratch state; no first-half reuse
has been introduced. Private candidates remain private. Unexpected errors
propagate without convenience fallback; known `QuietTrialRefusal` retains the
old rejection/fallback path.

Logical rejection does not establish equivalence of errors in an unperformed
half. Skipped physics and its error norm are NOT_MEASURED. New quota exhaustion
can occur later because skipped operations have no reserve/complete/refund.
Physical selected-path equality applies in the supported complete-leaf domain;
all historical failure timing is not claimed equal.

## Work and diagnostic scope

`quiet_work_for(policy)` and `quiet_work_type(policy)` select exact distinct
actual/forecast ledgers. Inherited full/half/fallback fields count only
performed reservations. Additional deterministic counters name first/second
performed halves, skipped halves, exclusive early reasons, measured guard/
regime/norm flags and proposal/fallback boundaries. Conservation checks bind
skips to those exclusive early reasons. These values persist and NEW restart
must reproduce them exactly; V4 work is not forged to agree.

`quiet_reason_counts_v5()` in Python and the typed extension exposes bounded
process-local diagnostic aggregates, separately ACTUAL/FORECAST/REFERENCE.
Each role has at most128 scalar keys and256 dominant/refusal labels; counters
saturate at2**63-1 with an explicit flag. Export is bounded by2MiB. No reset or
execution permission is supplied. Full/half/fallback wall and worker-CPU spans
start after reservation/stage accounting and end after sample validation;
clone, reservation and macro-decision costs are excluded. They are not whole
worker time. Timings are not persisted scientific/work state.

Native near-reason data records directly evaluated energy composite, thermal
margin and selected allocation flags. Curtailment *presence* and mode/allocation
context are reported separately; they do not attribute rejection causality.
Error-norm dominant named components are measured only when norm executes.
No claim about the cause of the historical88% rejection count is made before
the paid Q0 prefix. This initial file describes implementation, not test/run
evidence. Root owns all paid tests/builds/scientific launches.
