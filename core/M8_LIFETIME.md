# B62: конечная непрерывная кампания B61

Кандидат поверх source721 B61. Native V8 и вход V7, новый store/portable/accounting contract. Старые B59/B60/B61 producers не расширены. Новый producer проверяет полный текущий SOURCE_PATHS и raw SHA-256 каждого файла; actual worker повторяет admission и действительно входит в FAST context. Динамические ageing/orbit/thermal/battery состояния не кэшируются.

Вход сначала проходит loads_root/dumps_root и проверку исходного anchor. Отдельная duration-деривация меняет только duration_seconds и digest. Вторая явная B62 accounting-деривация меняет названия accounting и конечные накопительные квоты; физика, точность, начальные exposure, hardware и provenance не меняются. Никакой месяц не переинициализируется. 15 Julian years = 473364000 s; anchor128 →473364128. Это182 полных30-дневных периода и1620000 s (18.75дня).

Planner читает настоящие LifecyclePolicy, LifecyclePhysicsLimits, LifecycleOrbitPolicy, quiet/environment quotas. Формулы сохранены в resource_plan, включая условие числа advancing/instant transactions и forecast cuts. Это conditional finite admission, НЕ доказательство завершения: пространственные/construction/control дополнительные затраты и будущие physical/domain отказы остаются UNKNOWN. Все реальные guards/ledgers сохраняются и могут остановить расчёт; quota не увеличивается после paid work. Ни reservations, ни число операций не являются CPU временем. Поддержка длительности не означает рассчитанные годы.

Новый supervisor использует OS-held lock, append-only immutable bounded journal, deterministic intent keys и typed FINAL/owned settlement/publication/stream admission. UNKNOWN и forced suffix не продолжаются. Незавершённая отправка не повторяется автоматически. TIME/OUTPUT с подтверждённым прогрессом продолжаются; USER требует resume. status/read-only reopening не снимает pause и не запускает worker. Все jobs сохраняются; прежняя собственная ограниченная working-checkpoint политика не меняется. Один native без stream/publication/source/runtime closure не достаточен.

Native/report держит только текущий и последний sealed environmental bucket плюс cumulative chain/count. Все предыдущие месячные строки остаются в months streams. Counts, sums, integrals, E/V/I/R/T extrema и selected exposure/PV/epsilon/G объединяются при read-only export; forecast/loupe credits не добавляются к MAIN. Экстремумы sampled, не continuous bounds. Полный store с predecessors нужен для resume/loupe; result ZIP не даёт execution rights и может открываться через существующий Workbench portable inspector.

Shared data pool резервирует все design stores, metadata, initial package и дополнительную backup/export копию. Mirror не удваивает вместимость. Default4096 primary+4diagnostics ×128MiB на job намеренно консервативен; pool с одной дополнительной копией порядка1TiB. Это reserve/cap, не измеренный объём. Маленький pilot объявляет меньшую finite population ДО запуска. No cleanup/refund/deletion для обхода quota.

Производственный mode LINUX_PRODUCTION требует настоящий Linux/proc/dependencies/source doctor. WINDOWS_ONLY_LOCAL_QUALIFICATION — отдельная ограниченная policy, настоящий Windows OwnedJob, не Linux acceptance. Native не мигрирует между source/runtime/OS. Для long требуется bindable genuine Linux day/reference/fresh resume и шесть process protocol receipts; вручную выставленные PASS flags не принимаются. Docker build/wheels и actual Linux не объявлены проверенными.

Штатный Stop: отдельный serverctl stop, дождаться settled native/owned receipt. Docker stop/SIGTERM НЕ обещает checkpoint. Completion/Stop не отменяет аренду. Сначала export + отдельный полный store backup + проверка hashes, затем отдельная ручная отмена платных ресурсов. Никаких provider/network/upload/install операций этот код не выполняет.

B61 normal-assumed и accelerated-assumed rates различаются1e4; saved ускоренный день не прогноз flight lifetime. Этот блок не калибрует коэффициенты, не доказывает15лет survival/qualification и не завершает M. Combined qualification UNRESOLVED; B7 UNKNOWN.
