# B69 candidate: exact prepared report and compiled validation control

This is a bounded Windows/PILOT candidate. Numerical laws, grids, physics,
scientific fees and public V3 models/codecs remain B68. No speed factor is
claimed before the separately frozen public-parent paired measurements.

P1 forwards the current admitted ACTUAL role to report guard/offer/seal/
validation and separate FORECAST to received/estimated histories. Existing
eight-entry exact immutable history realizations are reused; no caller dict
success cache, unchecked incremental fold or actual/forecast sharing is added.
Report/projection dictionaries still pass complete canonical/type/value checks.
Public/untrusted/checkpoint calls without a private active role keep the full
reference validator. All original clocks/calendar/provenance/selected cuts,
quota/admission checks and finally-exit publication rules remain.

P2 prepares strong descriptors once, then compares them in typed C loops in
lifecycle_exact_guards.pxi. Attribute, exact pointer/type/builtin-value, ordered
mapping/tuple, callable code/default/keyword/closure and dataclass/Enum/Fraction
checks mirror the complete previous Python oracle. The existing owner
registries include unused owners; MROs, field flags/default factories/metadata,
properties/accessors, generation factories/closures and validation code itself
are retained. Full guard boundaries are unchanged. The B65 CLOSED generation
is retained, not rebranded as this implementation.

Two existing graph exceptions remain exactly bounded:

- non-init cached _identity: exact built-in string value, not arbitrary equality;
- ComponentAxisBinding.local_axis: exact three-float tuple, binary64 bits
  including signed zero. No other graph edge is interchangeable by value.

Native plans/arenas have private cdef fields and strong descriptor edges.
The owner index uses weak references so evicted histories do not retain an
unbounded sequence of plans. A live owner cannot receive a replacement plan.
Plans cannot be copied/pickled and are not checkpoint DATA. Admission checks the
genuine native source/runtime/binary, not merely a supplied capability dict.
Each arena is process/thread/job/source-bound, has at most262144 descriptor rows
per plan and128MiB conservative live reservations (1024+512bytes/row), with
bounded native operational counters. Closing the job invalidates the arena.
No undocumented CPython dict-version internals are accessed.

Python _full_snapshot/_owner_signature, _SchemaSeal.guard and _Seal.guard
remain declared reference/fallback oracles. Preparation checks the reference
and native plan once; production native boundaries do not execute both.
Descriptor preparation and original logical boundary/codec charges remain paid.
Cheaper checking refunds no scientific/control work.

Operational counters are deliberately separate from the stable context receipt.
Reading a binding receipt cannot invalidate a READY checkpoint by incrementing a
diagnostic counter. exact_guard_statistics() and guard_process_counts() expose
nonpersistent observational data, not continuation or execution authority.
Secondary annotation failures cannot hide an original body/callback exception.
Initial failures and corrections remain external evidence, not erased history.

The full native backend is explicit; missing/refused native cannot silently gain
a native/LONG grant. REFERENCE remains default. Fresh B69 roots/source admission
are required. B68-FROZEN remains immutable for the four companion lanes.

Composed V3 constructor units are unchanged and separately prepaid:
per materialize/admit owner2; preview2; NEW create4=materialize2+independent2;
preview+NEW create6; fresh store-object reopen2. Cache/plan creation is additional
finite operational validation, never a free design compilation.

Optional worker-operation fusion P3 is NOT_IMPLEMENTED. Stop polling, checkpoint
cadence, external callbacks, yield and public publication boundaries are retained.
No daily/month/year/Linux/cloud/H5 experiment is implied by this candidate.
Combined qualification remains UNRESOLVED; historical B7 cause UNKNOWN and
preservation FAIL1590/48/401 remain.
